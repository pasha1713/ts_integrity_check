## Описание

`ts_integrity_check.py` анализирует набор транспортных потоков MPEG-TS (`.ts`),
записанных видеорегистратором. Цель — определить, являются ли файлы
непрерывной записью с одного устройства или содержат признаки монтажа
(склейки, вырезания, вставки, перекодирования).

Скрипт рассчитан на файлы регистраторов на чипах **Novatek** и подобных,
но может применяться и к другим MPEG-TS-потокам.

Поддерживаются:

- H.264 (AVC)
- H.265 (HEVC)
- GPS-метки в отдельном PID
- PCR, PTS, DTS, Continuity Counter
- аудио- и видеодорожки

## Возможности

- Автодетекция фрагментов записи по разрывам GPS-времени, нумерации и mtime.
- Проверка GPS-времени и координат внутри и между файлами.
- Проверка PCR, PTS, DTS, Continuity Counter.
- Анализ NAL-типов H.264/H.265 (IDR, SPS, PPS, SEI, AUD).
- Поиск меток видеоредакторов (`SEI user_data_unregistered`, Filler NAL, множественные SPS).
- Спектральное сравнение аудио на стыках файлов.
- Сравнение яркости кадров на стыках.
- Перцептивный хэш (pHash) и MSE для кадров.
- Полный анализ всех кадров внутри файла.
- Анализ аудио: спектрограмма, поиск сегментов тишины.
- Проверка битрейта по сегментам.
- Проверка mtime и GPS-времени.
- Учёт «холодного пуска» GPS и заводских файлов.
- Формирование протокола, `error_details.txt`, `history_log.txt` и PNG-графиков.
